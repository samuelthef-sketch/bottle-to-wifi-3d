# Bottle-to-WiFi Machine (3D model)

An interactive 3D model of a reverse vending machine that turns empty plastic bottles into WiFi time, like piso WiFi but paid with bottles.

- Cabinet: 1/2" marine plywood, 50 × 50 × 120 cm
- Brain: ESP32 with capacitive, inductive, IR, load-cell and ultrasonic sensors
- Internet: pocket WiFi + OpenWrt router (captive portal)

Open `index.html` in a browser, or view it on GitHub Pages. Drag to rotate, use **See inside** for a cutaway, and **Play a bottle deposit** to watch one cycle.
